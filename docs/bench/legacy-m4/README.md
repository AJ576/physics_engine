# Old benchmark results (not reproduced)

These two files were in the repository root before the `engine-v2` branch.
They were produced by the old engine's `benchmark_suite` on an Apple M4 (per
the old README), with `std::rand` scenes that differ between macOS and Linux.
The engine they measured has been replaced, and they were not re-run. Current,
reproducible numbers are in [`docs/BENCHMARKS.md`](../../BENCHMARKS.md).
